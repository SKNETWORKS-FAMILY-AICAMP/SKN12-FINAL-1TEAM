# 🚀 시스템 통합 대시보드

PostgreSQL, MinIO, OpenSearch를 연동한 통합 모니터링 및 관리 대시보드입니다.

## 🔐 관리자 인증

대시보드는 관리자 권한이 필요하며, 로그인 후 사용할 수 있습니다.

### 초기 설정
1. **초기 관리자 생성**: 시스템에 관리자가 없을 때 "초기 관리자 생성" 버튼을 사용
2. **관리자 로그인**: 이메일과 비밀번호로 로그인
3. **세션 관리**: 로그인 상태는 세션에 저장되며, 로그아웃 버튼으로 세션 종료

### 관리자 권한
- 시스템 현황 모니터링
- 엔티티 관리 및 승인
- 시스템 설정 변경
- 데이터 내보내기

## 📋 기능

### 📈 시스템 현황
- 문서 업로드 현황 및 통계
- 자동 생성된 엔티티 현황
- 업로드 성공률 모니터링
- 시스템 연결 상태 확인

### 👥 엔티티 관리
- 직원, 고객, 제품 정보 관리

- 자동 생성된 데이터 확인

### ✅ 승인 시스템
- 자동 생성된 엔티티 승인/거부
- 승인 대기 목록 관리
- 승인 통계 및 현황

- 시스템 설정 관리

## 🚀 실행 방법

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. API 서버 실행
```bash
# FastAPI 서버가 실행 중인지 확인
# 기본 URL: http://localhost:8010
```

### 3. 대시보드 실행
```bash
streamlit run main.py
```

### 4. 브라우저에서 접속
```
http://localhost:8501
```

### 5. 관리자 로그인
1. 대시보드 접속 시 로그인 페이지가 표시됩니다
2. 관리자 계정으로 로그인하거나 초기 관리자를 생성합니다
3. 로그인 후 대시보드 기능을 사용할 수 있습니다

## 🔧 설정

### API 서버 URL 변경
`main.py` 파일에서 `API_BASE_URL` 변수를 수정하세요:

```python
API_BASE_URL = "http://your-api-server:8010"
```

### 환경 변수 설정
```bash
export API_BASE_URL=http://localhost:8010
```

## 📝 사용법

### 1. 관리자 로그인
- 이메일과 비밀번호 입력
- 관리자 권한 확인
- 로그인 성공 시 대시보드 접근

### 2. 시스템 현황 확인
- 사이드바에서 "📈 시스템 현황" 선택
- 실시간 통계 및 차트 확인

### 3. 엔티티 관리
- 사이드바에서 "👥 엔티티 관리" 선택
- 각 탭에서 직원/고객/제품 정보 확인
- 수동 등록 기능 사용

### 4. 승인 시스템
- 사이드바에서 "✅ 승인 시스템" 선택
- 승인 대기 중인 항목 확인
- 승인 또는 거부 처리

### 5. 설정 관리
- 사이드바에서 "⚙️ 설정" 선택
- 시스템 설정 변경
- 데이터 내보내기

### 6. 로그아웃
- 사이드바의 "🚪 로그아웃" 버튼 클릭
- 세션 종료 및 로그인 페이지로 이동

## 🔍 문제 해결

### 로그인 오류
1. 관리자 계정이 존재하는지 확인
2. 이메일과 비밀번호가 올바른지 확인
3. API 서버 연결 상태 확인

### API 연결 오류
1. FastAPI 서버가 실행 중인지 확인
2. `API_BASE_URL` 설정 확인
3. 네트워크 연결 상태 확인

### 데이터 로딩 오류
1. 데이터베이스 연결 상태 확인
2. API 엔드포인트 응답 확인
3. 로그 확인
